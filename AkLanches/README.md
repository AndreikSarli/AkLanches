# 🍔 AkLanches

Sistema de pedidos de uma lanchonete desenvolvido em **C#** como projeto acadêmico para praticar conceitos de **Programação Orientada a Objetos (POO)**.

## 📌 Sobre o projeto

O sistema funciona pelo console e permite montar e gerenciar pedidos de uma lanchonete.

É possível adicionar lanches, escolher ingredientes extras, adicionar bebidas e escolher seus tamanhos. Também é possível editar ou remover itens antes de finalizar o pedido.

## ⚙️ Funcionalidades

* Adicionar lanches ao pedido
* Adicionar ingredientes extras
* Adicionar bebidas
* Escolher o tamanho da bebida:

  * 300ml
  * 500ml
  * 700ml
* Editar itens do pedido
* Remover itens do pedido
* Calcular o subtotal
* Aplicar desconto em pedidos a partir de R$ 30,00
* Finalizar o pedido
* Tratamento de entradas inválidas

## 📚 Conceitos praticados

Durante o desenvolvimento foram utilizados conceitos de C# e POO, como:

* Classes e objetos
* Construtores
* Propriedades e encapsulamento
* Herança
* Polimorfismo
* Interfaces
* Listas (`List<T>`)
* Métodos
* Estruturas condicionais e de repetição
* Tratamento de exceções

## 🛠️ Tecnologias

* C#
* .NET
* Visual Studio

## ▶️ Como executar

1. Clone este repositório ou baixe os arquivos do projeto.
2. Abra o projeto no **Visual Studio**.
3. Abra a solução/projeto do AkLanches.
4. Execute o projeto pelo Visual Studio.
5. O sistema será iniciado no console e apresentará o menu principal.

## 🎓 Objetivo

Este projeto foi desenvolvido como parte dos estudos de **Programação Orientada a Objetos**, com o objetivo de praticar a criação de classes, herança, polimorfismo, interfaces e outras funcionalidades da linguagem C#.
